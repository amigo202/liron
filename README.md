# לירון – מתרגלת בנחת

אפליקציית תרגול אישית בעברית וב-RTL להכנה רגועה למבחני מיון.

## מה יש בפנים
- 100 שאלות מקוריות: 20 כמותי, 20 מילולי, 20 אנגלית, 20 אישיות, 20 אמינות.
- תרגול לפי נושא עם פידבק מיידי.
- מבחן קצר של 20 שאלות.
- מבחן ארוך של 100 שאלות עם שמירת התקדמות.
- מצב רגוע שמסתיר טיימר ומפחית עומס.
- מחברת טעויות, תבניות לזכור וכפתור "הסבירי לי אפילו יותר פשוט".
- כל ההתקדמות נשמרת ב-localStorage בדפדפן בלבד.

> זהו כלי תרגול מקורי בלבד, לא מבחן רשמי של תיל ולא העתק של שאלות מבחן אמיתיות.

## הפעלה
פתחו את `index.html` בדפדפן, או פרסמו את התיקייה כאתר סטטי (Netlify / GitHub Pages וכד').
