# לירון – מתרגלת בנחת

אפליקציית תרגול אישית בעברית וב-RTL להכנה רגועה למבחני מיון.

## מה יש בפנים
- 100 שאלות מקוריות: 20 כמותי, 20 מילולי, 20 אנגלית, 20 אישיות, 20 אמינות/יושרה.
- תרגול לפי נושא עם משוב והסבר פשוט אחרי כל תשובה.
- מבחן קצר של 15 שאלות מעורבות.
- מבחן ארוך של 50 שאלות מעורבות.
- מסרים מרגיעים וממוקדים לאורך התרגול.
- טיימר במבחנים המעורבים, בלי לחץ בתרגול לפי נושא.
- שאלוני אישיות ואמינות אינם מקבלים ציון; המטרה היא היכרות עם סגנון השאלות ועקרונות של כנות ועקביות.

> זהו כלי תרגול מקורי בלבד, לא מבחן רשמי של תיל ולא העתק של שאלות מבחן אמיתיות.

## הפעלה
פתחו את `index.html` בדפדפן, או פרסמו את התיקייה כאתר סטטי ב-Netlify / GitHub Pages.
